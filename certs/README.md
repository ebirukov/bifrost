# Корневые сертификаты

`ca-bundle.pem` — доверенные корни контейнера (SSL_CERT_FILE):
корпоративные CA Magnit + публичные корни (Mozilla). Файл — часть стэка,
коммитится и переносится вместе с ним.

Если корпоративный корень обновится — допиши новые сертификаты в начало
файла (публичные корни можно обновить из системы: на macOS
`cat /etc/ssl/cert.pem`, на Linux `/etc/ssl/certs/ca-certificates.crt`).
